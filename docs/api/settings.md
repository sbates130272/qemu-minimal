# Settings and fleet XML

Fleet XML is the only settings format. `fleet_xml` is the parser and the table the format lives in, `settings` finds the layers and turns them into what each command needs, and `fleet_schema` writes the two schemas and the [reference page](../fleet-xml.md) from the parser's tables.
