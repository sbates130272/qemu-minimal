    Inspection¶

    Reading what is running and what the host can run: list_vms and inspect for guests, summary for a fleet, check_system for the host, and ernic_stats, the exporter that serves the NIC servers' statistics to Prometheus.

    qemu_tool.list_vms ¶

    qemu-tool list: every QEMU running on this host, read from /proc.

    collect() returns one record for each QEMU process, taken from its command line: the guest's name, whether qemu-tool started it, its vCPUs and memory, image, SSH port, devices, and the container it runs in. run() prints them as a table or as JSON. inspect, summary and shutdown start from the same records.

    qemu_tool.inspect ¶

    qemu-tool inspect and qemu-tool ssh: one running guest in detail.

    records() starts from what list_vms.collect() reads off the QEMU process and adds what the image's sidecar and the guest agent say: the account, the SSH keys the guest accepts, its GPUs and their BARs, its block devices and who is logged in. run() prints the records, and ssh_argv() and ssh_run() build the ssh command from the same record, so ssh connects the way inspect said it would.

    def records(
    vm_name: str | None,
    xml: list[Path] | None,
) -> list[dict[str, Any]]:
    """Every running VM's record, or just one named VM's.

    Factored out of run() so `qemu-tool ssh` reaches a guest through exactly
    the same resolution inspect prints -- the username from the image's own
    sidecar, and the key the GUEST says it accepts rather than the configured
    default. A second implementation would be free to disagree with the
    output the user is reading, which is the whole failure this record exists
    to prevent.
    """
    try:
        vms = _collect_vms()
    except OSError as exc:
        sys.exit(f"Error: cannot read /proc: {exc}")

    if vm_name is not None:
        vms = [v for v in vms if v["name"] == vm_name]
        if not vms:
            sys.exit(f"Error: no running VM named {vm_name!r}")

    cfg = _load_config(xml)

    # One docker exec per VM at ~300 ms, serial, was 10.9 s over the 32-VM
    # fleet before this query grew any commands. executor.map keeps collect()
    # order so --json stays diffable between runs.
    if len(vms) > 1:
        with ThreadPoolExecutor(max_workers=min(8, len(vms))) as pool:
            return list(pool.map(lambda v: _record(v, cfg), vms))
    return [_record(v, cfg) for v in vms]

    def ssh_argv(
    record: dict[str, Any],
    strict_host_key: bool = False,
    extra: Sequence[str] | None = None,
) -> list[str]:
    """The ssh command for a VM record, as argv.

    Built from the record rather than from the config, so it agrees with what
    `inspect` printed: the username the image actually has, and an -i only
    when the guest named a key whose private half is on this host. When it did
    not, no -i is passed and ssh falls through to its other methods -- offering
    an identity the guest does not accept just buys a refusal.
    """
    port = record.get("ssh_port")
    if port is None:
        sys.exit(
            f"Error: {record['name']} has no host SSH port, so there is "
            "nothing to connect to.\n"
            "       Its qemu container publishes none -- check the stack's "
            "ports: mapping."
        )

    argv = ["ssh"]
    if not strict_host_key:
        argv += _SSH_LOOSE_HOST_KEY
    argv += ["-p", str(port)]
    if record.get("ssh_key_file"):
        argv += ["-i", record["ssh_key_file"]]
    argv.append(f"{record['username']}@{record.get('ssh_host') or 'localhost'}")
    argv += list(extra or [])
    return argv

    def ssh_run(
    vm_name: str,
    xml: list[Path] | None,
    strict_host_key: bool = False,
    extra: Sequence[str] | None = None,
    dry_run: bool = False,
) -> None:
    found = records(vm_name, xml)
    record = found[0]
    argv = ssh_argv(record, strict_host_key=strict_host_key, extra=extra)

    # Say why a password prompt is about to appear, BEFORE it appears. The
    # guest publishing only a key we do not hold is the common case on a fleet
    # booted from a published image, and an unexplained prompt reads as a
    # broken VM rather than a missing key.
    if not record.get("ssh_key_file"):
        note = record.get("ssh_key_note") or "no local key matched"
        print(f"Note: connecting without a key ({note}).", file=sys.stderr)
        for key in record.get("ssh_keys") or []:
            if key.get("accepted"):
                comment = f" {key['comment']}" if key.get("comment") else ""
                print(f"      guest accepts {key['fingerprint']}{comment}",
                      file=sys.stderr)

    if dry_run:
        print(shlex.join(argv))
        return

    try:
        # exec rather than subprocess: ssh wants the real tty for its password
        # prompt and for an interactive session, and the caller should see
        # ssh's own exit status, not a wrapper's.
        os.execvp(argv[0], argv)
    except OSError as exc:
        sys.exit(f"Error: cannot run ssh: {exc}")

    qemu_tool.summary ¶

    Fleet-level aggregate of list, plus a measured load picture.

    list prints one row per VM. On a large fleet that is 32 rows of mostly identical text, and the questions an operator actually has -- how much of this node is left, is anything on fire, is anyone logged in -- are not answerable by reading it. This is the aggregate of the same bytes, with four cheap host-side collectors and one opt-out guest-side one bolted on.

    Every number here has a defined unavailable state and renders it. A zero that means "could not measure" is the specific defect this module exists to avoid: an idle fleet and a fleet whose stats files could not be read look identical if the unreadable case contributes 0.

    Cost, measured on the live 32-VM mi100-fleet (100 containers, 192 cores):

    list's own collect()                      ~1.3 s
docker ps -a (compose labels, roll-call)  ~0.2 s
cgroup cpu/memory, 98 scopes, x2 samples  ~0.1 s
ernic stats, one docker exec for all 32   ~0.2 s
images: stat + qemu-img info 8-wide       ~0.2 s
the sample window itself                   5.0 s
guest sessions, 8-wide, overlapped         (hidden under the window)
------------------------------------------------
qemu-tool list --summary                   ~6.9 s
qemu-tool list --summary --no-guests       ~6.8 s

    The window dominates, and it cannot shrink much: the ernic servers rewrite their stats files at 1 Hz, so a window under ~2 s samples noise rather than a rate. docker stats --no-stream is deliberately not used anywhere -- it costs 4.2 s for 100 containers against 45 ms for the same numbers read out of cgroup v2 sysfs.

    def collect(vms: list[dict[str, Any]], *, guests: bool = True,
            sample_seconds: float = SAMPLE_SECONDS) -> dict[str, Any]:
    """One object, whatever the VM count.

    Deliberately not shaped like `inspect --json`, which prints a dict for one
    VM and a list for many: a consumer there has to sniff the type before it
    can read anything.
    """
    containers = _compose_containers()
    by_name = {c["name"]: c for c in containers.values()}
    groups = _group(vms, by_name)

    # The guest probe is the only collector that contacts a guest and the only
    # one that costs seconds rather than milliseconds, so it runs underneath
    # the sample window instead of after it. Started first, joined last.
    pool = None
    futures: dict[int, Any] = {}
    if guests and vms:
        pool = ThreadPoolExecutor(max_workers=min(8, len(vms)))
        futures = {id(v): pool.submit(_vm_sessions, v) for v in vms}

    try:
        ernic = {p: _ernic_fleet(p, containers) for p in groups}
        storage = {p: _storage(g) for p, g in groups.items()}
        first = _cgroup_sample(containers)
        proc_first = {v["pid"]: _proc_cpu(v["pid"]) for v in vms}
        t0 = time.monotonic()
        time.sleep(sample_seconds)
        elapsed = time.monotonic() - t0
        second = _cgroup_sample(containers)
        proc_second = {v["pid"]: _proc_cpu(v["pid"]) for v in vms}
    finally:
        if pool is not None:
            pool.shutdown(wait=True)

    sessions = {id(v): (futures[id(v)].result() if futures else None)
                for v in vms}

    host = _host()
    fleets = []
    for project, members in sorted(groups.items()):
        fleets.append(_fleet(
            project, members, containers, host, ernic[project],
            storage[project], first, second, proc_first, proc_second,
            elapsed, sessions, guests,
        ))
    return {
        "schema": 1,
        "sampled_seconds": round(elapsed, 2),
        "guests_probed": guests,
        "host": host,
        "fleets": fleets,
    }

    qemu_tool.check_system ¶

    qemu-tool check-system -- is this host able to run the stacks?

    Every failure this reports has been seen in the wild, and most of them present somewhere other than where they are caused: a missing kvm group looks like slow guests, an unreadable /dev/net/tun looks like a worker bug, a CONTAINER_USER typo looks like a stack that will not start for reasons the error does not name. The point of this command is to ask all of it up front, cheaply, before anything has been pulled or written.

    It is the same code qemu-tool quick-start runs in its preflight, not a copy of it -- quick_start imports from here. The repo has been bitten before by a documented path and its CI equivalent drifting apart, so there is one implementation and two callers.

    Nothing here writes anything or needs sudo. Read-only by construction, so it is safe to run on a host you have not decided to use yet.

    def loopback_publish_is_local(version: str) -> bool | None:
    """Whether Docker Engine `version` keeps a loopback publish to this host.

    None when the text does not start with major.minor: a daemon that could
    not be asked, or a version string this does not know how to read.
    """
    parts = version.strip().split(".")

        return (int(parts[0]), int(parts[1])) >= LOOPBACK_SAFE_ENGINE
    except (ValueError, IndexError):
        return None

    def engine_result(version: str) -> Result:
    """The `docker engine` line: the version, and what it means for loopback."""
    local = loopback_publish_is_local(version)
    if local is None:
        return Result("docker engine", _SKIP,
                      "the daemon did not report a version")
    if local:
        return Result("docker engine", _OK, version)
    floor = ".".join(str(n) for n in LOOPBACK_SAFE_ENGINE)
    return Result(
        "docker engine", _WARN,
        f"{version}: a port published on 127.0.0.1 is reachable from "
        f"machines on this host's network segment",
        f"Docker Engine {floor} is the first to keep a loopback publish to "
        f"the host; upgrade, or firewall the stack's SSH and Grafana ports")

    def kvm_usable() -> tuple[bool, str]:
    """The ioctl, not the node.

    A device node can exist and still be non-functional, and QEMU falls back
    to TCG without saying so. Guests under TCG will not finish inside any
    timeout worth setting, so this presents as "the fleet is hanging".
    """
    if not Path("/dev/kvm").exists():
        return False, "/dev/kvm is missing"
    try:
        import fcntl

        fd = os.open("/dev/kvm", os.O_RDWR)
    except OSError as exc:
        return False, (f"/dev/kvm cannot be opened ({exc.strerror}) -- "
                       "are you in the kvm group?")
    try:
        fcntl.ioctl(fd, 0xAE00, 0)
    except OSError as exc:
        return False, (f"/dev/kvm is present but KVM_GET_API_VERSION failed "
                       f"({exc.strerror})")
    finally:
        os.close(fd)
    return True, ""

    def report(groups: list[tuple[str, list[Result]]]) -> int:
    """Print the report and return the exit status.

    A FAIL sets 1; a warning does not. That asymmetry is the whole policy: a
    checker that failed on a merely tight host would be disabled in whatever
    runs it, and then catch nothing.
    """
    for title, results in groups:
        print(f"\n{title}")
        for r in results:
            line = f"  [{_MARK[r.status]}] {r.name}"
            if r.detail:
                line += f": {r.detail}"
            print(line)
            if r.hint and r.status in (_FAIL, _WARN):
                print(f"            {r.hint}")

    failed, warned = tally(groups)
    print()
    if failed:
        print(f"{failed} blocking problem(s), {warned} warning(s). "
              "The stacks will not run until the failures are fixed.")
        return 1
    if warned:
        print(f"No blocking problems, {warned} warning(s). "
              "Everything above marked 'warn' limits what this host can do, "
              "but nothing stops a stack starting.")
        return 0
    print("This host can run the stacks.")
    return 0

    qemu_tool.ernic_stats ¶

    Serve rocm-ernic stats files as Prometheus metrics.

    rocm-ernic -S PATH rewrites a human-readable stats dump every ~1s. This turns a directory of them into a Prometheus scrape endpoint, one series set per instance.

    Why this exists when rocm-ernic ships prometheus/ernic-exporter: that exporter is built for the systemd/ernicctl deployment. It requires an instances.json manifest that ernicctl writes, it only looks at files whose stem parses as an integer, and it reports liveness with pid_alive() against PIDs from its own namespace. None of those survive the compose stack, where each server is PID 1 in its own container and nothing writes a manifest. The CI container image also carries only the rocm-ernic binary -- no exporter, no ernicctl, no prometheus_client.

    So the code is separate but the schema is not: metric names, label names and the " : " parsing contract are taken from that exporter verbatim, so prometheus/grafana/ernic-dashboard.json works against this endpoint unmodified. Keep them in step.

    def parse(text: str) -> tuple[dict[str, int | str], dict[str, dict]]:
    """Split a stats dump into (device counters, {qp handle: counters}).

    The " : " separator is a documented contract of pvrdma_stats.c, which
    pads every label specifically so the value never touches the colon.
    """
    device: dict[str, int | str] = {}
    qps: dict[str, dict] = {}
    current_qp: str | None = None
    in_opcodes = False

    for raw in text.splitlines():
        line = raw.strip()
        if not line:
            in_opcodes = False
            continue
        if line.startswith("QP ") and line.endswith(":"):
            current_qp = line[3:-1].strip()
            qps.setdefault(current_qp, {"_opcodes": {}})
            in_opcodes = False
            continue
        if line == "WQEs by opcode:":
            in_opcodes = True
            continue
        if " : " not in line:
            # Any other bare "Section:" header ends the current QP. Without
            # this a device-level key printed after the per-QP block would be
            # attributed to the last QP seen.
            if line.endswith(":"):
                current_qp = None
                in_opcodes = False
            continue

        key, _, val = line.partition(" : ")
        key, val = key.strip(), val.strip()
        try:
            parsed: int | str = int(val)
        except ValueError:
            parsed = val

        if current_qp is not None:
            if in_opcodes:
                qps[current_qp]["_opcodes"][key] = parsed
            else:
                qps[current_qp][key] = parsed
        else:
            device[key] = parsed

    return device, qps

    def collect(stats_dir: Path) -> str:
    """Render every *.stats file under stats_dir as Prometheus text."""
    instances = []
    for path in sorted(stats_dir.glob("*.stats")):
        match = _ID_RE.search(path.stem)
        ident = match.group(1) if match else path.stem
        try:
            device, qps = parse(path.read_text())
        except OSError:
            # The server rewrites the file in place with no atomic rename, so
            # a scrape can land mid-write. Skipping beats emitting zeros,
            # which would look like a counter reset to Prometheus.
            continue
        _ROLES[ident] = backend_role(device, ident)
        instances.append((ident, device, qps))

    out: list[str] = []
    out.append("# HELP ernic_instances Number of rocm-ernic instances found")
    out.append("# TYPE ernic_instances gauge")
    out.append(f"ernic_instances {len(instances)}")

    def emit(name: str, help_text: str, kind: str, samples: list[tuple[str, int]]) -> None:
        if not samples:
            return
        out.append(f"# HELP {name} {help_text}")
        out.append(f"# TYPE {name} {kind}")
        for labels, value in samples:
            out.append(f"{name}{{{labels}}} {value}")

    for metric, key, help_text in _INSTANCE_COUNTERS:
        emit(metric, help_text, "counter", [
            (f'ernic_id="{_escape(i)}",role="{_escape(_role(i))}"', _as_int(d, key))
            for i, d, _ in instances
        ])

    for metric, keys, help_text in _INSTANCE_AGGREGATES:
        emit(metric, help_text, "counter", [
            (f'ernic_id="{_escape(i)}",role="{_escape(_role(i))}"',
             sum(_as_int(d, k) for k in keys))
            for i, d, _ in instances
        ])

    for metric, key, help_text in _QP_COUNTERS:
        emit(metric, help_text, "counter", [
            (f'ernic_id="{_escape(i)}",role="{_escape(_role(i))}",qp="{_escape(qp)}"',
             _as_int(stats, key))
            for i, _, qps in instances
            for qp, stats in sorted(qps.items())
        ])

    emit(_WQE_METRIC, "WQEs processed on this QP by opcode", "counter", [
        (f'ernic_id="{_escape(i)}",role="{_escape(_role(i))}",'
         f'qp="{_escape(qp)}",opcode="{_escape(opcode)}"', count)
        for i, _, qps in instances
        for qp, stats in sorted(qps.items())
        for opcode, count in sorted(stats.get("_opcodes", {}).items())
        if isinstance(count, int)
    ])

    return "\n".join(out) + "\n"

    def backend_role(device: dict, ident: str) -> str:
    """What this server is to the mesh, from the backend its dump records.

    `tcp:manager:...` is the manager and `tcp:worker:...` a worker; any other
    backend (loopback, nvmeof, s3, none) is not a mesh node, and its name is
    the role. A dump with no backend line is an older server's: instance 1
    is then the manager and the rest workers, as the generated stack wired
    every fleet before a NIC could name a backend.
    """
    backend = str(device.get("backend", "")).strip()
    if not backend:
        return "manager" if ident in ("1", "1-1") else "worker"
    kind, _, rest = backend.partition(":")
    if kind != "tcp":
        return kind
    return "manager" if rest.startswith("manager") else "worker"

    def run(stats_dir: Path, port: int, addr: str) -> None:
    class Handler(BaseHTTPRequestHandler):
        def do_GET(self) -> None:  # noqa: N802 - http.server API
            if self.path.rstrip("/") not in ("", "/metrics"):
                self.send_error(404)
                return
            body = collect(stats_dir).encode()
            self.send_response(200)
            self.send_header("Content-Type", _CONTENT_TYPE)
            self.send_header("Content-Length", str(len(body)))
            self.end_headers()
            self.wfile.write(body)

        def log_message(self, *args) -> None:
            pass  # one line per scrape per VM is pure noise at fleet scale

    if not stats_dir.is_dir():
        print(f"Warning: {stats_dir} does not exist yet; serving an empty set",
              file=sys.stderr)
    server = HTTPServer((addr, port), Handler)
    print(f"Serving rocm-ernic metrics from {stats_dir} on {addr}:{port}/metrics",
          file=sys.stderr)
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        pass
