# qemu-minimal

Live VM inspection reports, regenerated by CI. Each is produced by
[`scripts/generate-vm-report.sh`](https://github.com/sbates130272/qemu-minimal/blob/main/scripts/generate-vm-report.sh)
against a guest booted in that lane, so it reflects the VM as CI
actually built it rather than what the docs claim.

| Report | Lane | What it covers |
|---|---|---|
| [Single VM](1vm/) | `vm-report` | One `gen-vm` guest with an NVMe device, booted on a GitHub-hosted runner. |
| [Two VMs — VM 1](two-vm/) | `vm-report-two-vms` | The `vfio-user-ernic-2vm` compose stack, both guests with a rocjitsu GPU. |
| [Two VMs — VM 2](two-vm/vm2/) | `vm-report-two-vms` | The second guest of the same stack. |

Each lane runs on its own schedule and publishes independently, so
the reports here are not all from the same moment; each page carries
its own generation timestamp and commit.

Source: [sbates130272/qemu-minimal](https://github.com/sbates130272/qemu-minimal)
